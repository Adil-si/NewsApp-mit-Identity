# NewsApplicationV2

Kleine ASP.NET Core MVC Anwendung zum Verwalten von Medien‑Dateien (Bilder/Videos) mit Benutzer‑Zuordnung.

## Features

- Upload von Bildern und Videos
- Auflistung aller Uploads (Index‑Seite)
- Detailansicht eines Eintrags
- Löschen eines Eintrags mit Bestätigungsseite (inkl. Vorschau des Bildes/Videos)
- Speicherung der Daten in einer SQL‑Datenbank über Entity Framework Core

## Technischer Stack

- .NET / ASP.NET Core MVC
- C#
- Entity Framework Core
- Razor Views
- SQL Server (oder LocalDB)
- Bootstrap für das Layout
